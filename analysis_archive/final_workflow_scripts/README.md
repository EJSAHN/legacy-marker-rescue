# Final workflow scripts

This directory is reserved for exact run scripts if a separate DOI archive is prepared. Scripts placed here should be the final manuscript workflow scripts only, with local paths removed, display-item drawing code removed, and exploratory troubleshooting branches excluded.

The public GitHub companion repository does not require these scripts for numerical validation. Manuscript headline values are validated from `data/source/Supplementary_Data_S1.xlsx` by `scripts/validate_source_data.py`.
