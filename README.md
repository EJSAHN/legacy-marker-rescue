# Legacy Marker Rescue

Tools for extracting candidate bands from molecular-marker images, simulating single-primer RAPD products from genome assemblies, and evaluating the resulting profiles. The repository contains the analysis implementation, fixed study inputs, and software tests.

## Run from a checkout

Python 3.10 or newer, NumPy, SciPy, and Pillow are required. Mash is required for genome-distance recalculation; Windows can use a Mash installation in the default WSL distribution. The image analyses do not require Mash, a GPU, or model weights.

```bash
python -m pip install -r requirements.txt
python -B run_pipeline.py selftest
python -B run_pipeline.py detection --output-dir ../results/denoyes
python -B run_pipeline.py external --output-dir ../results/external
```

The detection command uses the supplied public-domain source image and reader-defined lane boundaries. It exports band candidates and correspondence tables, not final genotypes. The external command retrieves two checksummed image/mask collections from the GelGenie data deposit on first use. Downloads are cached.

For the complete study workflow, supply a local input file as described in [Inputs and outputs](docs/usage.md):

```bash
python -B run_pipeline.py all --inputs local_inputs.json --output-dir ../results/complete_run
```

This runs the genome analysis, historical-product context calculation, lane-guided image analysis, and external image benchmark in order. Outputs must be outside the source checkout. A nonzero exit code means a stage was interrupted or incomplete; partial results and the error record are retained.

## Analyses

- Genome analysis: single-primer site enumeration, explicit inward-facing product selection, binary band profiles, Jaccard/Mash comparisons, matrix-label permutations, fixed random-primer comparisons, and assembly-level split evaluation.
- Genome context: matched-length background intervals, sequence composition, contig-edge proximity, and gene context where suitable annotation is supplied.
- Image analysis: background-corrected lane profiles, candidate positions, uncertainty flags, and correspondence with partial reader observations.
- External benchmark: image-derived lane proposals and point-to-foreground matching. Native-resolution, resized-image, and reference-geometry analyses are reported separately.

The numerical implementation is shared by the command-line workflow and the tests. Fixed inputs are in `data/`; analysis settings are in `config/`; the implementation is in `legacy_marker_rescue/`.

## Interpretation

Inward-facing products are the primary simulation model. The earlier opposite-order site enumeration is retained only as a diagnostic comparison. Repeated assembly splits are internal assessments, not independent biological cohorts. Size correspondence does not establish locus identity.

The Denoyes reader observations are approximate and incomplete, and the reader had prior exposure to earlier detector results. Unmarked positions are not verified absences. Candidates remain candidates until adjudicated. The heterogeneous external image collection is a stress test, not an additional RAPD population dataset.

[Analysis definitions](docs/analysis.md) documents the metrics and denominators. [Sources](docs/sources.md) describes input provenance and reuse conditions. The workflow writes analytical tables and numerical arrays. Publication figures and supplementary workbooks are not generated by these commands.
