# Analytical inputs

`genome/` contains the fixed assembly inventory, historical and random-primer sequences, previous-model distance/profile inputs, and curated legacy size/summary tables. These tables support orientation diagnostics and numerical comparisons; they are not a replacement article supplementary workbook.

`denoyes/` contains a credited public-domain source image, its reader record and protocol, approximate-reading scope, prior detector coordinates, and a lane-only geometry example. Unreviewed, uncertain, and draft states are preserved. The example geometry does not include reader band positions or exclusion masks.

Input files are covered by the repository content manifest. Run outputs, raw genome files, external image archives, drafts of the article, and local input manifests are not versioned here.
