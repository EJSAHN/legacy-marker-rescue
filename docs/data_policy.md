# Data policy

This repository stores derived data products rather than publisher-owned source images.

## Include

- bibliographic metadata and retrieval instructions;
- crop templates and coordinate metadata;
- derived band-coordinate tables;
- derived band presence/absence matrices;
- tolerance grids and QC summaries;
- source-data workbooks used to validate manuscript display items;
- reusable analysis utilities and validation scripts.

## Do not include

- raw publisher PDFs unless redistribution is explicitly permitted;
- cropped publisher figures from copyrighted sources;
- manuscript display-item drawing code;
- exploratory troubleshooting wrappers;
- local machine paths or user-specific directories.

Public-domain source material may be used according to its source terms and with customary credit. Even when reuse is permitted, this project favors derived matrices and audit tables for the public analysis archive.
