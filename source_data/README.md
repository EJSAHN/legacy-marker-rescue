# Source data

`Supplementary_Data_S1.xlsx` is the derived source-data workbook used by `scripts/validate_source_data.py`. It contains the tables underlying the manuscript figures and tables, including pairwise distance tables, band matrices, random-primer summaries, detected-segment tables, tolerance grids, bridge tables, and lane-level audit outputs.

The journal supplementary file should be treated as the canonical copy after publication. The copy in this repository is included as a compact validation fixture so that the public code can recompute the manuscript headline values without requiring raw publisher PDFs or figure crops.
